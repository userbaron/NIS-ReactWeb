# Мини-маркет

Домашнее задание со слайда 34: React, TypeScript, styled-components.

Нужен Node.js 22.12 или новее. В папке S05:

```bash
npm install
npm run dev
```

Сборка: `npm run build`. Проверка сборки в браузере: `npm run preview`.

Две темы имеют общий тип AppTheme, который расширяет DefaultTheme. Без сохранённого выбора используется prefers-color-scheme; ручное переключение сохраняется в localStorage. Все цвета находятся в theme.ts. UI-кит содержит Button, Badge, Card, Input и Grid; внизу страницы можно раскрыть все 12 сочетаний вариантов и размеров кнопок. Сетка меняется с одной до четырёх колонок на ширине 600, 900 и 1200 пикселей.

Добавление в корзину имитирует запрос задержкой 600 мс, без бэкенда. Кнопка на это время блокируется и показывает спиннер. Корзина хранится в памяти до перезагрузки страницы.

## styled-components против CSS Modules на моём проекте

В этом проекте styled-components позволяет держать стили кнопки рядом с её состояниями и пропсами. Цвета берутся из типизированной темы, поэтому обе темы используют одни и те же компоненты. Варианты и размеры кнопки выбираются через transient props, которые не попадают в DOM. С CSS Modules мне пришлось бы описывать отдельные классы вариантов и выбирать их в компоненте. Зато CSS Modules не требует вычислять стили в браузере, а цвета можно было бы переключать через CSS-переменные. Для этого небольшого каталога styled-components удобен связью стилей с TypeScript, но для большого списка товаров я бы также учитывал стоимость его работы во время выполнения.
